# SecureAuth

> SecureAuth is an enterprise identity security company. Its platform verifies who or what is acting, decides what they may do, and keeps deciding after login, for employees, customers, partners and AI agents.

## Company

SecureAuth has secured large enterprises for more than 20 years and now runs one platform for workforce, customer, B2B and AI agent identity. The difference from login-only identity products is continuous authority: every session and every action is evaluated against risk and policy as it happens, not once at sign-in. SecureAuth is a certified FAPI 2.0 provider, stewards the Impacket open-source project, and is named a Leader in the KuppingerCole Leadership Compass for CIAM.

## Products

### Agent Authority (AI agents)
Agent Authority is SecureAuth's zero-trust control layer for AI agents. It sits on the call between every agent and the tools, APIs, data and models the agent reaches, and decides each action as it happens: which agent is acting, for which person or team, on what, and whether policy allows it. Each agent run gets its own short-lived identity instead of a borrowed human login or a standing API key, so one instance can be revoked or downscoped without touching the rest. Sensitive data is classified and redacted in flight, prompt injection is caught before the agent acts on it, spend is metered and capped per agent and team, and every decision, denials included, is recorded in the Agent Trail with the rule that made it. It runs downstream of the identity provider you already have, needs no agent rewrite or SDK (an MCP-capable agent is pointed at one brokered endpoint), and enforces at three points: the MCP gateway for tool calls, the endpoint where agents run, and the LLM path for prompts sent to model providers.
URL: https://secureauth.com/products/agent
Full technical detail: https://secureauth.com/llms-full.txt

What it covers, in the product's own terms:
- Agent identity and discovery: a register of every agent with a named owner, shadow-agent discovery on devices and in SaaS, non-human identity discovery for the service accounts and keys agents rely on, human attribution for every action.
- Runtime authorization and enforcement: every tool call checked against policy before it runs, down to the operation and its arguments; destination control; context-aware policy on who is asking, the task, the data and its risk; instant containment of a single agent instance.
- Detection and risk: per-instance behavioral baselines, identity risk findings for over-privileged, stale or shared credentials, access and exposure assessment.
- Prompt and data protection: context-aware redaction, sensitive data classification, prompt injection defense, secret and credential detection.
- Cost and operational controls: rate limits and quotas, spend attribution to agent, person and team, spend caps, adoption and utilization.
- Evidence and traceability: the Agent Trail, a verdict record for every allow, deny, hold and redaction, SIEM, SOAR and XDR forwarding.

## Key Concepts

- **Continuous Authority**: SecureAuth's model for identity security. Authentication and authorization do not end at login; every session and every action is re-evaluated against risk, context and policy while it happens.
- **Agent Authority**: the Continuous Authority model applied to AI agents. Each agent run is an identity of its own, each tool call is authorized per request, and the record of what the agent did is kept whether the call was allowed or denied.
- **Per-request authorization**: a decision made on every tool call or API request, using the agent acting, the delegating user, the operation and its arguments, the data involved and its risk, rather than a role granted once at login.
- **No standing credentials**: agents receive short-lived, narrowly scoped tokens over OAuth 2.1 instead of long-lived API keys or a person's own login embedded in code or configuration.
- **Agent Trail**: the per-action record in Agent Authority: the agent, the person behind it, the arguments carried, the context, and the rule that decided the call.
- **Microperimeter**: fine-grained access control enforced at the action level rather than at the application boundary.
- **Private SaaS**: dedicated, single-tenant infrastructure with full SaaS management, combining cloud convenience with on-premises control.
- **Composable security**: deploy only the identity components you need under one governance model.
